# MindScroll
MindScroll is a modern and responsive blog website built using React, HTML, CSS, and Tailwind CSS. It provides a clean and engaging platform for users to explore blogs, articles, and creative content with a smooth user experience.

## Features

* Responsive and modern UI design
* Clean blog layout with attractive sections
* Fast and smooth navigation
* Reusable React components
* Styled using Tailwind CSS
* User-friendly reading experience
* Optimized for desktop and mobile devices

## Technologies Used

* React
* HTML
* CSS
* Tailwind CSS
* JavaScript

## Project Purpose

The purpose of MindScroll is to create a visually appealing and functional blog platform where users can read and explore content easily. It focuses on simplicity, performance, and a modern design approach.

## Installation

1. Clone the repository

```bash
git clone https://github.com/sheikhzahra047-ship-it/MindScroll
```

2. Navigate to the project folder

```bash
cd MindScroll
```

3. Install dependencies

```bash
npm install
```

4. Run the development server

```bash
npm run dev
```
